# RunLume dashboard tour

Meet RunLume, a local-first dashboard for AI coding sessions. This is the real
application using synthetic data; no personal transcript is included. The live
overview shows token flow, cost coverage, code impact, and tool reliability.
Verified rates power cost estimates, while unknown models stay unpriced. Provider comparison
separates sources from Nemotron, Kimi K3, GLM 5.2, Qwen 3.6, and Mistral.
Successful tool results drive workflow metrics. Trajectories are redacted by
default, and everything stays on localhost without telemetry.
