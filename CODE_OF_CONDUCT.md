# Code of conduct

RunLume follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, specific, and constructive. Harassment, discrimination, threats, doxxing, and publication of another person's private data are not accepted.

Report conduct concerns privately through this repository's [private reporting form](https://github.com/mlvpatel/RunLume/security/advisories/new) or any contact method listed on the maintainer's GitHub profile. Include only the information needed to investigate. The maintainer may remove content or restrict participation when this code is violated.
